What Is PDI Retail Site Management? PDI Retail Site Management is a mobile-first ERP built for convenience retail. It moves core store tasks, inventory checks, cash counts, paperwork, and order reviews from the back-office desktop onto mobile devices, so teams can manage the store from the floor in real time.
